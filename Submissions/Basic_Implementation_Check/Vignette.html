Monte Carlo Simulation of a Hypothesis Test Vignette

library(Survive380AnnaTheBest)
library(ggplot2)

This vignette demonstrates how to estimate the Type I error rate, Type II error rate, and power of a hypothesis test for binomially distributed samples using Monte Carlo simulation, via four functions from the Survive380AnnaTheBest package:

  • Calculates the p_values under observed data and standard error using Monte Carlo sampling Survive380AnnaTheBest::mc_pval_binom

  • Calculates the null p_value under null hypothesis Survive380AnnaTheBest::mc_pval_null

  • Estimate Type I error Survive380AnnaTheBest::mc_type1_binom

  • Estimate Type II error and power at a specific \(p_{1}\) Survive380AnnaTheBest::mc_power_simple_binom

  • Estimate power curve across a grid of \(p\)-value Survive380AnnaTheBest::mc_power_curve_binom

We will produce:

  1. A summary table of Type I, Type II error and power

  2. A histogram of simulated \(p\)-value with a vertical line at \(\alpha\)

  3. A power curve plot

Quick assumption check

Since we are using normal approximation to perform z-test, a common assumption is both \(np_{0}\) and \(n(1-p_{0})\) should be reasonably big (\(\ge 10\))

p_0 <- 0.5
n <- 50

c(np0 = n * p_0, n1p0 = n * (1 - p_0))

Estimated \(p\)-value

Computing \(p\)-value under a observation

set.seed(1)
p_0 <- 0.5 # success probability
sample_size <- 50 # number of trials
alternative <- "less"
s_obs <- 20 # s_obs: number of success observed in one data set

p_value <- mc_pval_binom(
  p_0 = p_0,
  s_obs = s_obs,
  sample_size = sample_size,
  alternative = alternative
)

p_value$p_value
#> [1] 0.102969
p_value$mc_se
#> [1] 0.0009610694

Histogram of null \(p\)-value under \(H_{0}\)

# following code used to compute null p_value under H_0
set.seed(1)
p_0 <- 0.3
sample_size <- 60
alternative <- "less"

p_values <- mc_pval_null(
  p_0 = p_0,
  sample_size = sample_size,
  alternative = alternative
)

alpha <- 0.05  # significance level

rejections <- (p_values < alpha) # for checking rejection region (FYI)

# plot
ggplot(data.frame(p_value = p_values), aes(x = p_value)) +
  geom_histogram(bins = 30, fill = "cornflowerblue", color = "black", alpha = 0.7) +
  geom_vline(xintercept = alpha, color = "red", linetype = "dashed", linewidth = 1) +
  annotate(x = alpha, y = +Inf, label = paste("α =", alpha), vjust = 2, 
           geom = "label", size = 3, color = "red") +
  # Add shaded rejection region
  annotate("rect", xmin = 0, xmax = alpha, ymin = 0, ymax = Inf,

  labs(title = "Histogram of Simulated P-Values",

Power vs. Sample Size Curve

#This indicates the sample size required to achieve the desired test capability. 
# Here, we use 80% as an example.

#set initials
sample_sizes <- seq(10, 200, by = 10)
M <- 1000
p_true <- 0.65  
p_null <- 0.5
alpha <- 0.05
power_results <- numeric(length(sample_sizes))

for(i in 1:length(sample_sizes)) {
  n <- sample_sizes[i]
  p_hat <- rbinom(M, n, p_true) / n
  z_stats <- (p_hat - p_null) / sqrt(p_null * (1 - p_null) / n)
  p_values <- 2 * pnorm(-abs(z_stats))
  power_results[i] <- mean(p_values < alpha)
}
df_power <- matrix(c(sample_sizes, power_results),
                   ncol = 2,
                   dimnames = list(NULL, c("SampleSize", "Power")))
achieved_target <- df_power[df_power[, "Power"] >= 0.8, , drop = FALSE]
if (nrow(achieved_target) > 0) {
  required_n <- achieved_target[1, "SampleSize"]
  cat("To achieve 80% test power，we need at least n =", required_n, "\n")
} else {
  cat("fail to reach 80% test power，please enhance the sample size \n")
}
#> To achieve 80% test power，we need at least n = 80
