Monte Carlo Simulation of a Hypothesis Test Vignette

library(Survive380AnnaTheBest)

This vignette demonstrates how to estimate the Type I error rate, Type II error rate, and power of a hypothesis test for binomially distributed samples using Monte Carlo simulation, via four functions from the Survive380AnnaTheBest package:

  • Calculates the p_values and standard error using Monte Carlo sampling Survive380AnnaTheBest::mc_pval_binom

  • Estimate Type I error Survive380AnnaTheBest::mc_type1_binom

  • Estimate Type II error and power at a specific \(p_{1}\) Survive380AnnaTheBest::mc_power_simple_binom

  • Estimate power curve across a grid of \(p\)-value Survive380AnnaTheBest::mc_power_curve_binom

We will produce:

  1. A summary table of Type I, Type II error and power

  2. A histogram of simulated \(p\)-value with a vertical line at \(\alpha\)

  3. A power curve plot

Quick assumption check

Since we are using normal approximation to perform z-test, a common assumption is both \(np_{0}\) and \(n(1-p_{0})\) should be reasonably big(often \(\ge 10\))

p_0 <- 0.5
n <- 50

c(np0 = n * p_0, n1p0 = n * (1 - p_0))
#>  np0 n1p0 
#>   25   25

Estimated p-value

Computing p_val

set.seed(2000)
p_0 <- 0.5 # success probability
sample_size <- 15 # number of trials
alternative <- "less"
s_obs <- 10 # s_obs: number of success observed in one data set

p_value <- mc_pval_binom(
  p_0 = p_0,
  s_obs = s_obs,
  sample_size = sample_size,
  alternative = alternative
)

p_value

#> [1] 0.9415306

draw the plot of power curve

library(ggplot2)
ggplot(power_curve, aes(x = p_true, y = power_hat)) +
  geom_line(color = "dodgerblue", linewidth = 1.2) +
  geom_point(color = "dodgerblue", size = 2) +
  geom_errorbar(aes(ymin = power_hat - 2*power_mc_se, 
                    ymax = power_hat + 2*power_mc_se), 
                width = 0.01, color = "grey50", alpha = 0.5) +
  geom_hline(yintercept = 0.05, linetype = "dashed", color = "red") +
  annotate("text", x = min(power_curve$p_true), y = 0.08, 
           label = "Significance Level (0.05)", color = "red", hjust = 0, size = 3) +
  labs(title = "Power Curve of Binomial Test",
       subtitle = paste("Numbers of trails =", sample_size, ", Probability of success =", p_0, ",Alternative =", alternative),
       x = "True Probability (p)",
       y = "Power (Probability of Rejecting H0)") +
  theme_minimal() +
  theme(plot.title = element_text(face = "bold"))
